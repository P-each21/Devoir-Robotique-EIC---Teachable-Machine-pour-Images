# Devoir-Robotique-EIC---Teachable-Machine-pour-Images

Ce que j’ai appris
J’ai appris à utiliser Teachable Machine pour entraîner un modèle d’intelligence artificielle capable de reconnaître trois classes d’objets : les ciseaux, la lumière (lampe) et le bouquin (livre). J’ai compris que le modèle apprend à partir des images fournies afin d’identifier des caractéristiques visuelles et de distinguer les différentes classes. Lors des tests avec la webcam, j’ai observé des scores de confiance de 100 % pour les objets présentés dans mes captures d’écran. Cette expérience m’a permis de comprendre que la qualité et la diversité des images sont importantes pour obtenir un modèle plus fiable.
Fonctionnement du programme
Le fonctionnement du projet se déroule en trois étapes. D’abord, je collecte des images des trois classes à l’aide de la webcam, avec environ 40 à 44 images par classe. Ensuite, je lance l’entraînement afin que le modèle apprenne à distinguer les objets à partir des exemples fournis. Enfin, je teste le modèle en présentant différents objets devant la webcam: il analyse les images, compare leurs caractéristiques à ce qu’il a appris et affiche un score de confiance pour chaque classe. La classe qui obtient le score le plus élevé correspond à la prédiction du modèle.
Difficultés rencontrées au programme
J’ai rencontré quelques difficultés pour obtenir des prédictions fiables et comprendre les résultats du modèle. J’ai notamment dû faire attention à la manière de présenter les objets devant la webcam, car l’éclairage, l’angle de prise de vue et l’arrière-plan peuvent influencer les prédictions. J’ai également compris qu’un score de confiance de 100 % ne garantit pas que le modèle reconnaîtra correctement l’objet dans toutes les situations. Pour améliorer les résultats, il serait utile d’ajouter davantage d’images variées pour chaque classe et de tester le modèle dans différentes conditions.
